# 🎵 CuteDJ - 智能音乐DJ Agent

一个可爱的桌面虚拟助手，为你智能推荐音乐！

## ✨ 特性

- 🎀 可爱的桌面虚拟角色
- 💬 智能对话推荐音乐
- 🎧 多平台音乐支持 (Spotify/网易云/QQ音乐)
- 🎭 根据心情推荐歌曲
- 📊 音乐口味分析

## 🛠️ 技术栈

- **前端**: Next.js + TypeScript + Tailwind CSS
- **桌面**: Tauri (Rust)
- **AI**: Claude API + LangChain
- **动画**: Live2D / Framer Motion

## 📦 安装

```bash
# 克隆仓库
git clone https://github.com/crfRex/cutedj-agent.git

# 安装依赖
cd cutedj-agent
npm install

# 启动开发服务器
npm run dev
```
